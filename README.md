# SmartPoints Homebrew Tap

Install SmartPoints CLI tools via Homebrew.

## Usage

```bash
# Preferred branding alias
brew tap smartpoints/tap https://github.com/SmartPointsTech/homebrew-tap
brew install spt
```

```bash
# Canonical GitHub owner/repo tap
brew tap smartpointstech/tap
brew install spt
```

## Available Formulae

| Formula | Description |
|---------|-------------|
| `spt`   | SmartPoints CLI |
